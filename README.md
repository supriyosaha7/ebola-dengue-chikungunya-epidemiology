# Epidemiological Data Collection and Analysis – Research Internship

## 📌 Project Overview
This repository contains my research internship report on the collection, organization, and visualization of infectious disease surveillance data.

The internship focused on three major diseases:
- Ebola – Democratic Republic of Congo
- Dengue – Multi-country analysis
- Chikungunya – Madagascar

## 🎯 Internship Objectives
- Collect and organize epidemiological case data.
- Analyze dengue case trends across ten locations.
- Create time-series visualizations using R and RStudio.
- Develop practical skills in data cleaning and scientific reporting.

## 🛠️ Tools & Technologies
- R
- RStudio
- Base R
- tidyverse
- dplyr
- tidyr
- ggplot2
- readr
- Microsoft Excel
- Dropbox

## 📊 Key Work
- Collected Ebola surveillance data.
- Compiled dengue case data across ten locations.
- Created monthly and weekly dengue case visualizations.
- Collected chikungunya data for Madagascar (2025).
- Examined seasonal patterns and data quality issues.
